# Dynamic Data Dashboard

A small FastAPI backend and Streamlit frontend showing dynamic metrics. Run locally:

1. Create venv and install: python -m venv .venv  ;  .venv\Scripts\activate  ;  pip install -r requirements.txt
2. Start API: uvicorn api.main:app --reload --port 8000
3. Start UI: streamlit run streamlit_app.py
4. Or run with Docker Compose: docker-compose up --build

Features:
- /metrics endpoint returning the latest synthetic metric
- /metrics/history?n=NUM returns the last NUM points (server keeps a rolling buffer)
- Streamlit dashboard loads recent history and polls the API for live updates
- Docker + docker-compose and GitHub Actions CI (pytest)

What's impressive:
- Real-time-like data generated by a background producer (FastAPI background task)
- History endpoint and a polished Streamlit dashboard you can show in demos
- Ready for Docker and CI so it's GitHub-ready
